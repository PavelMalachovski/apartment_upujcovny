# Апартаменты · интерактивный 3D-тур

Прогулка от первого лица по двухуровневым апартаментам с террасой,
восстановленным по фотографиям и поэтажному плану. Чистый Three.js,
без сборщика и без внешних зависимостей во время работы страницы.

## Быстрый старт

Двойной клик по `tour/index.html` — работает офлайн, сервер не нужен.

Если браузер ограничивает локальные файлы, подними мини-сервер:

```bash
python -m http.server 8000 --directory tour
```

и открой `http://localhost:8000/`.

## Управление

| Клавиши | Действие |
|---|---|
| **WASD** / стрелки | ходьба |
| **мышь** | осмотр (клик по экрану захватывает курсор) |
| **Shift** | быстрый шаг |
| **Esc** | вернуть курсор |

Лестница на второй этаж — за раздвижной дверью в северной стене кухни.
С верхнего этажа через западную дверь выходишь на террасу.
Мини-карта справа вверху показывает план текущего этажа и позицию камеры,
слева внизу — название комнаты.

## Деплой на Vercel

Проект статический, сборка не нужна. `vercel.json` уже указывает
`outputDirectory: "tour"`, поэтому тур открывается прямо на корневом URL.

**Через веб-интерфейс:** на [vercel.com/new](https://vercel.com/new) импортируй
этот репозиторий, framework preset оставь **Other**, build command пустой —
остальное подхватится из `vercel.json`. Каждый push в `main` пересобирает прод.

**Через CLI:**

```bash
npx vercel --prod
```

## Структура

| Путь | Что внутри |
|---|---|
| `tour/index.html` | Страница тура, разметка и стили интерфейса |
| `tour/apartment.js` | Данные квартиры: стены, проёмы, полы, лестница, мебель, свет |
| `tour/builder.js` | Строитель сцены: процедурные текстуры, материалы, геометрия |
| `tour/controls.js` | Управление от первого лица: коллизии, переходы между этажами |
| `tour/app.js` | Инициализация, цикл рендера, мини-карта, подписи комнат |
| `tour/three.min.js` | Three.js r128, локальная копия |
| `docs/superpowers/specs/` | Дизайн-спека проекта |

## Точность модели

Геометрия снята с поэтажного плана: расположение стен, проёмов, окон и
лестницы соответствует ему. Размерных линий на плане нет, поэтому масштаб
откалиброван по стандартной мебели (кровать 180 см, глубина кухонной
столешницы 60 см, ступень ~20 см). Погрешность порядка 5–10% — для
визуализации незаметна, для замеров модель использовать нельзя.

Детализация — уровень «средняя+»: вся крупная мебель и встроенные шкафы стоят
на своих местах с реальными цветами и материалами, мелкий декор (вазы, книги,
посуда) опущен намеренно.

Исходные фотографии квартиры в репозиторий не попадают — они в `.gitignore`.
